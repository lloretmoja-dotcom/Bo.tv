# BH Channels

App Android para ver canales públicos, locales, deportivos y satelitales desde iptv-org.

## Características
- Carga automática de miles de canales de `iptv-org.github.io`
- Filtro por país y búsqueda por nombre
- Reproductor con ExoPlayer (HLS / DASH / MP4)
- Tema oscuro Material 3

## Compilar
1. Clona este repositorio.
2. Abre en Android Studio.
3. Sincroniza Gradle y ejecuta.
